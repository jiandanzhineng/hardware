# CUNZHI01 产品定义（第二代寸止设备）

## 1. 产品定位

CUNZHI01 是第二代寸止设备。它的产品层不是单一“设备说明”，而是由两条使用路径组成：

- 手机端玩法：当前主推，面向新手和日常使用，连接更简单，流程更短。
- 电脑端玩法：进阶模式，功能更复杂，适合多设备联动、参数化控制和更完整的玩法编排。

## 2. 当前主推方向

当前对外宣发和默认推荐，以**手机端玩法**为主。

原因主要是：

- 上手更快
- 连接步骤更少
- 更适合开箱、演示和短视频传播
- 对新用户的理解成本更低

电脑端玩法保留为进阶方案，适合需要更复杂控制逻辑、更多设备联动和更强可配置性的场景。

## 3. 手机端玩法

手机端主要通过 `CUNZHI01 APP` 或兼容 BLE 的手机端工具连接设备。

当前手机版内置两种玩法：

1. 寸止玩法
2. 踮脚提肛玩法

这两种玩法的参数、交互和字段定义，见：

- [CUNZHI01 APP开发说明](../app/CUNZHI01_APP开发说明.md)

### 3.1 寸止玩法

- 以压力传感为核心
- 通过实时压力判断节奏
- 支持起飞期、惩罚期、冷静期等状态
- 更适合做为手机端的主展示玩法

### 3.2 踮脚提肛玩法

- 以双通道压力判断为核心
- 同时关注提肛与踮脚状态
- 参数更丰富，但对新手仍保持可解释性

## 4. 电脑端玩法

电脑端以 PC 控制面板为入口，适合更复杂的控制和编排。

它的特点不是“单个玩法”，而是更完整的控制系统能力：

- 设备管理
- MQTT / mDNS 管理
- 游戏与玩法管理
- 当前运行页
- 固件 OTA
- 日志与自动化测试

对应文档可参考：

- `CUNZHI01设备定义.md`：偏硬件、属性、协议和固件实现

## 6. 结论

CUNZHI01 的产品定义应明确为：

**第二代寸止设备，手机端玩法为主推，电脑端玩法为进阶补充。**
