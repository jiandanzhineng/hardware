# RT01 设备定义（乳头按摩：气泵 + 气压 + 电机）

本设备以 ESP32-C3 为核心，集成吸气泵、泄压阀、I2C 气压传感器、乳头电机正反转及电池管理。  
第一版只做远程属性控制，不实现设备内玩法。

原理图：`SCH_Schematic1_2026-08-24.pdf`（主板 0.1 / V1.0）

## 设备标识

- 设备类型：`RT01`（新增时需按《新增设备类型指南》在固件中注册）
- 适用场景：乳头按摩，负压吸附 + 电机揉搓
- 硬件版本：V1.0
- 主控：ESP32-C3

## 硬件接口

| 功能模块 | 信号名称 | GPIO | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 电池监测 | BAT_ADC | GPIO 0 | ADC | 电池分压采样 |
| 电池监测使能 | BAT_EN | GPIO 1 | 输出 | 高电平使能采样，用完拉低 |
| 按键 | KEY1 | GPIO 2 | 输入 | 吸气，按住一直吸，松开停 |
| 按键 | KEY2 | GPIO 3 | 输入 | 泄压，按住开阀，松开关阀 |
| 电磁阀 | YV | GPIO 4 | 输出 | 开=泄压，关=保压 |
| 气泵 | PUM | GPIO 5 | 输出 | 开=吸气，关=不吸 |
| 气压 I2C | SCL | GPIO 6 | I2C | 与 QIya 同款传感器 |
| 气压 I2C | SDA | GPIO 7 | I2C | 与 QIya 同款传感器 |
| 按键 | KEY3 | GPIO 8 | 输入 | 电机切换：停→正转→反转→正弦转→停 |
| LED | LED | GPIO 10 | 输出 | 联网指示，作 CONNECTED_LED |
| 电机 | INA | GPIO 18 | PWM/输出 | BA6208 输入 A |
| 电机 | INB | GPIO 19 | PWM/输出 | BA6208 输入 B |

电池测量复用 `components/Battery`，逻辑与 CUNZHI01 相同。

## RT01 设备属性

| 属性名 | 类型 | 读写 | 描述 | 默认值 | 范围/枚举 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `pressure` | float | 只读 | 当前气压 (kPa) | 0 | -40–40，与 QIya 同传感器 |
| `target_pressure` | float | 读写 | 目标气压 (kPa)，闭环吸气阈值 | 0 | 不得低于 `min_pressure` |
| `min_pressure` | float | 读写 | 允许的气压下限 (kPa) | -40 | -40–0，出厂等于传感器下限 |
| `deflate` | int | 读写 | 泄压 | 0 | 0=保压, 1=泄压 |
| `motor` | int | 读写 | 电机强度 | 0 | -100–100，0=停，正=正转，负=反转 |

不暴露 `pump`、`motor_mode`、`report_delay_ms`、`temperature`。不上报温度，不做单独定时上报，只走通用心跳 `report`。

## 气路逻辑

- 气泵开 = 吸气（腔体气压下降，负压增大）
- `deflate=1` = 泄压（腔体回到大气压）
- 泵关且不泄压 = 保持当前气压
- 泄压时必须关泵，二者不得同时开

## 气压闭环

只做「偏高才吸」，不做自动泄压。

- 当 `pressure` > `target_pressure`：开泵吸气
- 当 `pressure` <= `target_pressure`：不操作（关泵）
- 泄压只由 `deflate=1` 或泄压按键触发，闭环不会自动开阀
- 气泵状态不暴露为属性，只在固件内控制
- 写 `target_pressure` 低于 `min_pressure` 时夹紧到 `min_pressure`
- `pressure` <= `min_pressure` 时强制关泵（按住吸气键也停）
- 不限制单次吸气时间

远程停吸：把 `target_pressure` 改回 0 即可。默认 0 时静止约 0 kPa 不会自动吸。

## 电机

驱动芯片 BA6208，`INA`/`INB` 控制方向与转速。

- `motor`：-100 ~ 100。0=停；正数=正转强度；负数=反转强度。
- 正弦转是按键切入的本地状态，不暴露属性。周期约 10 秒，幅度取 `|motor|`。
- `|motor|=0` 时按电机键进入正/反/正弦：强度按最大 100。
- 写 `motor` 会退出正弦，按符号正转/反转/停。`motor=0` 立即停。
- 正弦过程中不改写 `motor` 属性。

## 按键

按住有效，松开即停（电机键除外，点按切换）。

- **KEY1 吸气**：按下一直吸（开泵，不看目标气压）；松开后回到闭环。触达 `min_pressure` 仍强制关泵。
- **KEY2 泄压**：按下 `deflate=1` 开阀并关泵；松开 `deflate=0`。
- **KEY3 电机**：点按切换 停 → 正转 → 反转 → 正弦转 → 停。

## 消息与上报

协议遵循 `docs/MQTT消息类型与格式.md`。新设备只用 set / get / update / report / action。

设置目标气压：

```json
{"method":"set","key":"target_pressure","value":-15,"msg_id":4001}
```

设置电机：

```json
{"method":"set","key":"motor","value":60,"msg_id":4002}
```

泄压：

```json
{"method":"set","key":"deflate","value":1,"msg_id":4003}
```

不另做周期上报。可读属性只随通用心跳 `report` 带出。

按键事件：

```json
{"method":"action","action":"key_clicked"}
```

## 行为与约束

- 气压驱动与采样参考 QIya（I2C 地址 `0x6D`，SCL=6，SDA=7）。
- 电机 PWM 由 `|motor|` 映射到 BA6208 一侧占空比，另一侧保持低。
- `deflate=1` 时强制关泵。
- 无 `game_*` 属性，不做设备内玩法。
- 电池：采样前拉高 GPIO 1，采完拉低。
